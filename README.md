# school-break-map

Interactive map for school break schedules (greenfield starter).

## Development

```bash
npm ci
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

| Command | Description |
| --- | --- |
| `npm run dev` | Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run lint` | ESLint |
| `npm run preview` | Preview production build |

Cloud Agent bootstrap is defined in [`.cursor/environment.json`](.cursor/environment.json).
